# Legacy reference asset

This folder is not part of the application build. Its historical site image is kept here for reference only.

Active static assets, including the Ankara Display font family, live under `Webclient.app/public/`. Exact duplicate font files were removed from this legacy folder after verifying that each Git blob was identical to its active public counterpart.

The old `configservices.csv` and source-site font stylesheet were moved to `docs/archive/legacy-site-reference/`. The CSV represents the retired server-configured service-catalogue design and must not be used to reintroduce an application API dependency.
